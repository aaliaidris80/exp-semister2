# WD-II Experiment Solutions

This folder contains solutions for the 12 assignments from `WD-II EXPERIMENTs LIST.pdf`.

## Files

1. `exp1.html` - Responsive web page using Bootstrap grid system
2. `Bootstrapexp2.html` - Bootstrap UI components: navbar, cards, badges, modal
3. `tailwind.html` - Mobile-first FitLife landing page using Tailwind CSS
4. `exp4.html` - JavaScript marks calculator using variables, loops, and conditions
5. `exp5.html` - Employee records using arrays and objects
6. `exp6.html` - DOM manipulation and JavaScript event handling
7. `exp7-react-props.html` - React components using JSX and props
8. `exp8-react-counter.html` - React counter using `useState`
9. `exp9-react-form.html` - React registration form with validation
10. `exp10-java-oop/BankManagementSystem.java` - Java OOP bank management system
11. `exp11-spring-rest/` - Spring Boot Student REST API
12. `exp12-spring-crud/` - Spring Boot Employee CRUD REST API

## Run

- HTML files: open directly in a browser.
- Java OOP: run `javac BankManagementSystem.java` and then `java BankManagementSystem` inside `exp10-java-oop`.
- Spring Boot projects: install Maven, then run `mvn spring-boot:run` inside the project folder.
